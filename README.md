## 下单前必须确认的六件事

英国服务器大多是自管型产品，很多坑藏在条款里而不是配置里。付款前把这六项过一遍：

1. **交付时间**。独服不是付款即用，有商家明确写着付款后 3 个工作日内交付，而且计费从下单付款那一刻就开始算——赶上线的日子要把这几天算进去。
2. **续费和取消的通知期**。有的机房要求提前 7 个工作日通知，低于这个期限才去续费，可能被加收 300 元手续费。白纸黑字写在租用说明里的条款。
3. **自管还是托管**。多数英国服务器是自管型：系统、软件、数据备份全部自己负责，商家只管硬件、网络和重启。备份别指望任何人。
4. **带宽口径**。国际还是本地、独享还是共享、有没有月流量上限，三个问题都要拿到明确答案。
5. **防御能力**。各家差别很大：有的部分节点免费 20G 防御、峰值可到 300G，有的只给免费基础防护。业务有被攻击风险的话，下单前把这个谈清楚。
6. **内容红线**。垃圾邮件、侵权内容、扫描入侵在英国机房都是明确禁止项，被投诉会直接停机。
